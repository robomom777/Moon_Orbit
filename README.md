# 🌎 Moon Orbit

A little journey through space, created with HTML and CSS!

Moon Orbit is a CSS animation project featuring a rotating Earth, 
an orbiting Moon, and a twinkling star field.
What started as a simple exercise in positioning
and animation turned into a miniature space scene.

## ✨ Features

- 🌎 Textured Earth with a rotating animation.
- 🌙 Textured Moon orbiting Earth.
- 💙 Blue atmospheric glow surrounding Earth.
- ✨ Soft lunar halo effect.
- 🌌 Animated twinkling stars in the background.
- 🪐 Smooth, continuous orbital animation.

## 🛠️ Built With

- HTML5
- CSS3
- CSS Animations
- CSS Transforms
- CSS Positioning
- CSS Gradients
- CSS Box Shadows

## 🎨 What I Practiced

This project helped me practice and explore:

- Creating nested HTML elements.
- Using relative and absolute positioning.
- Centering elements with CSS transforms.
- Creating animations with `@keyframes`.
- Combining multiple transform functions.
- Using radial gradients to create stars.
- Adding depth with box shadows and glowing effects.
- Working with background images.

## 🚀 What I Learned

One of my biggest takeaways was understanding
how CSS transforms work together.

I also learned how to troubleshoot animation issues
and discovered that preserving the original
positioning transform is important when animating an
element that has already been centered.
